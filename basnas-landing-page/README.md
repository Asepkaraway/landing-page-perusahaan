# BASNAS Landing Page

## Overview
This project is a modern landing page for BASNAS, a private company focused on providing social services and community support. The landing page is designed to present the company's profile, services, testimonials, and a contact form for inquiries.

## Project Structure
```
basnas-landing-page
├── src
│   ├── index.html        # Main HTML document for the landing page
│   ├── styles
│   │   └── main.css      # CSS styles for the landing page
│   ├── scripts
│   │   └── main.js       # JavaScript for interactive features
│   └── data
│       └── company.json   # Structured data about the company
├── package.json          # npm configuration file
├── .gitignore            # Files and directories to ignore in version control
└── README.md             # Documentation for the project
```

## Features
- **Responsive Design**: The landing page is designed to be fully responsive, ensuring a seamless experience on both desktop and mobile devices.
- **Company Profile**: Detailed information about BASNAS, including its mission and vision.
- **Services Offered**: A section highlighting the various services provided by the company.
- **Testimonials**: A section for client testimonials to build trust and credibility.
- **Contact Form**: An interactive contact form for users to reach out for inquiries or support.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd basnas-landing-page
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open `src/index.html` in your web browser to view the landing page.

## Usage
- Modify the content in `src/data/company.json` to update company information.
- Customize styles in `src/styles/main.css` to change the appearance of the landing page.
- Add interactive features in `src/scripts/main.js` as needed.
